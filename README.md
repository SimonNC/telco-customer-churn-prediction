# Customer Churn Prediction

## 📌 Business Context
Customer churn is a major challenge for telecom companies, as acquiring new customers is significantly more expensive than retaining existing ones.

This project focuses on predicting customer churn in order to identify at-risk customers and support data-driven retention strategies.

## 🎯 Project Objective
Build a binary classification model capable of predicting whether a customer is likely to churn, with the goal of prioritizing retention actions and reducing overall churn rate.

## 📊 Dataset
- Source: Telco Customer Churn dataset (IBM)
- Each row represents a single customer
- Target variable: `Churn` (Yes / No)

## 🧠 Approach
- Business understanding and problem framing  
- Exploratory Data Analysis (EDA) focused on churn drivers  
- Feature engineering based on business insights  
- Baseline and improved classification models  
- Model evaluation using churn-oriented metrics  
- Simple Streamlit application for customer scoring
